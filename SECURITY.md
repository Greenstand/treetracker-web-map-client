# Security policy

This policy is for the code of this repo, the Treetracker web map client.

## How to report a security problem

Do not open a public issue or a public pull request for a security problem. A public report shows the problem to everyone before a fix exists.

Send a private report on GitHub:

1. Open the ["Security and quality" tab](https://github.com/Greenstand/treetracker-web-map-client/security) of this repo.
2. Select "Report a vulnerability".
3. Describe the problem, the steps that show it, and its effect.

Only the maintainers of this repo can read your report.

Do not put real personal data or real secrets in the report. Say where they are.

## What happens next

- A maintainer answers in the private report. Greenstand is a volunteer project, so an answer can take some days.
- The maintainers tell you in the report when the problem is fixed.

## What is not a security report

- A bug that has no effect on security: open a normal [issue](https://github.com/Greenstand/treetracker-web-map-client/issues).
- A known vulnerability in a dependency that does not affect this app: open a normal issue.
